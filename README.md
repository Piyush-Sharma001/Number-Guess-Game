# 🎯 Number Guessing Game

A simple and interactive **Number Guessing Game** built using **HTML5, CSS3, and JavaScript** for learning and practicing JavaScript fundamentals.

In this game, the player tries to guess a randomly generated number within a limited number of attempts. The project was created as a beginner-friendly exercise to understand JavaScript logic, user input, random numbers, and game flow.

## 🚀 Features

* 🎯 Random Number Generation
* 🔢 User Number Guessing
* ⏳ Limited Attempts
* 💬 Instant Feedback
* 🎉 Win & Game Over Messages
* 📊 Score Tracking
* 🔄 Interactive Gameplay
* 📱 Responsive Design

## 🎮 How to Play

1. Start the game.
2. Enter your guessed number.
3. The game checks your guess against the randomly generated number.
4. Continue guessing within the available attempts.
5. Try to guess the correct number before your attempts run out.
